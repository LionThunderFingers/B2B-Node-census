Scope

These are reachable nodes only. A crawler can only count nodes that accept incoming connections. Nodes behind NAT or a firewall that never listen are invisible to it, so every figure here is a lower bound on the real network, not a total. Version shares are shares of what is reachable.

Are nodes agreeing on the chain?

Each node reports its block height during the handshake. A cluster stuck well behind the rest is the first visible sign of a chain split.

Distance from the highest block seen Nodes

Heights are as of each node's last handshake, not this instant, so some of the spread is crawl recency rather than real lag. A genuine split would show as a persistent cluster in the bottom row across several updates.

How this is measured
  • A crawler connects to each node on port 8333 and completes a Bitcoin handshake, recording the services, block height and software it reports. Nothing here is second-hand.
  • Fork nodes are identified by service bit 28 (0x10000000, NODE_BLAKE2B).
  • A node reporting the fork bit while running software with no BLAKE2b support is counted as reachable but flagged, since it is either misconfigured or misreporting.
  • Regenerated hourly. The timestamp above is when the figures were taken, not when you opened the page.
